# RecFace — Product Profile

## IDGate
- **Use case:** Access control
- **Features:** Time entry
- **Compute:** Main CPU
- **Additional feature:** Tracking (requires GPU)

## IDTime
- **GPU support:** Yes
- **Deployment options:** On-premise (recommended), Virtual machine, Physical machine, Private cloud
- **Network:** Same network as IP cameras — uses RTSP
- **Features:**
  - Time tracking
  - Can work with a tablet
  - Visitor management

## TimeStreet
- **Features:** Schedule, absence, lunch duration tracking
- **Dashboard** included
