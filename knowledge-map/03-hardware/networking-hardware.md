# Networking Hardware — Reference

## Switch Types
| Type | Description |
|---|---|
| **Unmanaged** | Plug-and-play; no advanced configuration options |
| **Managed** | Supports advanced configs: QoS, VLAN, LACP |
| **L2 Switch** | Operates at Layer 2 (switching within same network) |
| **L3 Switch** | Can also **route traffic** (Layer 3 capability) |
| **PoE Switch** | Provides both data **and power** over a single cable — governed by PoE standards (802.3af/at/bt) |

## SFP / SFP+
- Small form-factor pluggable transceivers — hardware modules used to connect switches/devices via fiber (or copper via DAC).
- **DAC (Direct Attach Cable)** — 2 hardware ends used to form a direct link (typically for short-distance, high-speed connections between switches).

## Cabling
| Cable Type | Speed | Max Distance | Notes |
|---|---|---|---|
| **Cat5** | 100 Mbps | 100 m | Used to connect devices within a LAN |
| **Cat6** | 10 Gbps | *(typically ~55m at 10Gbps, 100m at lower speeds)* | Higher-speed LAN cabling |
| **Fiber — Single Mode** | High | Long distance | Used for long-haul links |
| **Fiber — Multi Mode** | High | Short distance | Used for shorter in-building/campus links |
