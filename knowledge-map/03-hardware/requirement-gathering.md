# Requirement Gathering & Sizing

## Questions to Ask the Client
- **Resolution** required
- **FPS** required
- **Retention days** (how long footage must be stored)
- **Analytics** needed (which types)
- **24/7 recording?** or event-based only
- **Motion-based recording?**

## What to Calculate From the Above
- **Storage** (see formula below)
- **CPU** requirement
- **RAM** requirement
- **Network bandwidth** requirement

## Storage Formula
```
Storage (GB) = Bitrate (Mbps) × 3600 (sec→hr) × Hours/Day × No. of Cameras × Retention Days ÷ 8000 (Mb→GB)
```

## PoE Switch Capacity
```
(Total wattage of all cameras) + 20% safety margin  ≤  Switch PoE budget
```

## Network Bandwidth
```
(Mainstream bitrate + Substream bitrate, summed across cameras) × 1.25  ≤  Switch uplink capacity
```

## Network Sizing Considerations
When sizing the network for a deployment, account for:
- **Camera bitrate** (per camera, mainstream + substream)
- **Stream count** (how many streams per camera, and total across the site)
- **Analytics placement** — on-cam vs on-server affects where bandwidth/compute load falls
- **Event metadata** — additional data generated by analytics events (separate from raw video)
- **Snapshot transport** — bandwidth used by periodic snapshot uploads (e.g. ANPR/FRS snapshot mode)
- **Storage retention** — longer retention = more storage, and can affect read/write bandwidth during archival
- **VMS integration overhead** — additional bandwidth/compute consumed by the VMS layer itself (indexing, thumbnails, client connections, etc.)

## What Affects Bandwidth
- **Higher resolution** → higher bandwidth
- **Higher FPS** → higher bandwidth
- **Codec** — efficiency of the compression codec used (e.g. H.264 vs H.265) directly affects bandwidth
- **GOP** (Group of Pictures) structure — affects compression efficiency and bandwidth
- **Scene complexity** — a busy/high-motion scene needs more bandwidth than a static one
- **Edge AI** — processing on the edge saves bandwidth (only metadata/events sent upstream instead of full video)

## Symptoms of High Network Load
If the network is overloaded, expect:
- High latency
- Packet loss
- Jitter
- Server overload
