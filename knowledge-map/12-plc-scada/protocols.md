# PLC / SCADA / BMS — Communication Protocols

## Full Forms
- **PLC** — Programmable Logic Controller
- **SCADA** — Supervisory Control and Data Acquisition
- **BMS** — Building Management System

## Communication Protocols
| Protocol | Used By | Notes |
|---|---|---|
| **Modbus** | PLC/SCADA | One of the oldest, widely supported industrial protocols |
| **Profibus** | PLC/SCADA | Common in factory/process automation |
| **Ethernet/IP** | PLC/SCADA | Industrial Ethernet-based protocol |
| **OPC UA** | PLC/SCADA | Modern, platform-independent, secure industrial data exchange standard |
| **BACnet** | BMS | Standard protocol for building automation/management systems |
