# Genetec — Product Profile

## Editions
- **Vanilla**
- **Enterprise**
  - With failover
  - Without failover

## Storage Options
- **DAS** (Direct Attached Storage)
- **NAS** (Network Attached Storage) — 2-server setup
- **SAN** (Storage Area Network)

## File Format
- Uses **G.264** encoding *(raw notes said "G.164 encryption" — likely means the G.264 video codec, not an encryption standard; confirm exact term before relying on it)*
