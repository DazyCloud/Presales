# Camera Types

| Type | Application |
|---|---|
| **Dome** | Ceiling-mounted, rounded housing; directional ambiguity deters tampering. Lobbies, retail, corridors, banking halls |
| **Bullet** | Cylindrical, wall/bracket-mounted, highly visible deterrent, long IR range (40–100m). Perimeters, parking, building exteriors |
| **PTZ (Pan-Tilt-Zoom)** | Remote pan/tilt/zoom, 20x–40x optical zoom, auto-tracking, preset patrol tours. Covers one area at a time — stadiums, highways, large open areas |
| **Turret / Eyeball** | Ball-and-socket design, no dome glass so no IR reflection at night, easy to repoint. Entries, stairwells, server rooms |
| **Fisheye** | Ultra-wide 180°/360° view from a single ceiling mount; de-warping software corrects distortion. Open-plan retail, warehouses, atria |
| **Multi-Sensor / Panoramic** | 2–8 independent sensors in one housing, each with its own lens, full resolution per zone. Road intersections, large car parks, airport aprons |
| **Box / C-Mount** | Accepts interchangeable C-mount lenses for specialised applications. LPR lanes, industrial process monitoring |
| **Covert / Pinhole** | Hidden inside objects/fixtures for discreet monitoring. Loss prevention, undercover investigation |
| **Thermal** | Detects heat signatures instead of visible light — works in total darkness, smoke, fog. Perimeter detection at night, fire/hotspot detection, industrial monitoring |
| **Explosion-Proof / ATEX** | Rugged, certified housing rated for hazardous/flammable environments. Oil & gas, chemical plants, mining |
| **ANPR / LPR Camera** | Specialised bullet/box camera tuned for fast shutter + IR for plate capture. Vehicle barriers, toll plazas, parking entries |
| **Speed Dome** | A PTZ variant optimised for very fast, precise movement and tracking. City surveillance, traffic monitoring, stadiums |
| **Body-Worn Camera** | Portable, worn by personnel, own onboard storage/battery. Law enforcement, security guards, field staff |
| **Panoramic (single-sensor wide)** | Ultra-wide single-lens (non-fisheye) coverage for elongated spaces. Corridors, platforms, warehouse aisles |

> Selection depends on coverage requirement, mounting location, environment, and analytics requirement — see [`01-solution-design/decision-framework.md`](../01-solution-design/decision-framework.md).
